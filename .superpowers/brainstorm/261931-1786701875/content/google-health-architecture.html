Security boundaries

  • Read-only Google scopes
  • Per-user Clerk ownership checks
  • Encrypted refresh tokens
  • Single-use, expiring OAuth state
  • Verified webhook authenticity

Reliability boundaries

  • All-history paginated backfill
  • Webhook-triggered incremental imports
  • Daily reconciliation
  • Idempotent external IDs
  • Visible sync status and failures
