# HomeFit logo

The logo combines a house, sunrise and health pulse using the app's orange and
midnight navy palette. It was generated with the built-in image generation tool.

Assets in `src/lib/assets/`:

- `homefit-logo.png`: 256px transparent logo, displayed by `Wordmark.svelte`.
- `favicon.png`: 32px transparent browser tab icon.
- `apple-touch-icon.png`: 180px icon on a light background for Apple devices.

The shared wordmark supplies the accessible app name; its adjacent logo is decorative.
The root layout supplies the icons on every route.

## Generation prompt

Use case: logo-brand. Create one polished flat logo symbol for HomeFit, a
self-hosted dashboard uniting sleep, training and health. Symbol only, no text.
A strong minimal geometric house silhouette incorporating a sunrise/horizon and
a subtle fitness rhythm. Match the app's existing warm burnt orange accent and
deep midnight navy palette. Bold simple silhouette with very few shapes, crisp
vector-like edges, legible at 24 pixels as a favicon. Centered square composition,
generous but not excessive padding, truly transparent background. No gradients,
shadows, mockups, textures, fine details or additional symbols. Deliver a single
standalone brand mark.

Generated padding was trimmed and the mark was resized with a consistent safe
area for each asset. The Apple touch icon uses an opaque light background.
